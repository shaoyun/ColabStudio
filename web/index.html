连接说明

导入时优先查找本机 EasyColab 环境或 ~/.colab-cli-oauth-config.json；找不到时可选择 google-colab-cli 包内的 oauth_config.json。“导入配置”只读取客户端配置；“复用已有登录”会读取 EasyColab / Colab CLI 凭据，验证后复制到本应用 Keychain，不改动原文件。

点击浏览器授权，选择 Google 账号并允许访问，将结果页显示的授权码粘贴回此处。凭据保存到 macOS Keychain。

已有自建 Desktop app？使用下方高级设置。新授权请求 Colab 与账号基本信息（邮箱和名称）；复用的凭据保留原授权范围，本应用仅使用所需功能。

高级设置：自建 OAuth client
  1. 在 Google Cloud 项目启用 Colab API。
  2. 配置 OAuth consent screen，添加测试用户。
  3. 创建 Desktop app OAuth client，将 Client ID 和 Client secret 填入上方并保存。
  4. 点击本地回调授权，在浏览器完成登录。
